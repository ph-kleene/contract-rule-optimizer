# 方法来源与发布范围

公开版以 v5 的两层优化方法为基础。先对每条规则做润色和质量审核，待所有规则进入稳定状态后，再把完整规则列表逐篇对照合同；每次合同校验的结果作为下一份合同的输入。

## v5 与 stage1_5 的区别

| 项目 | v5（本发布实现） | stage1_5（实验路线说明） |
| --- | --- | --- |
| 校验单位 | 一份合同 + 全部当前规则 | 一条规则 + 检索到的相关片段 |
| 合同上下文 | 全文 | 片段及其检索覆盖范围 |
| 状态更新 | 按合同顺序迭代整个规则集合 | 按规则分别处理 |
| 外部依赖 | 配置的文本模型服务 | 文本模型服务、嵌入模型和检索索引 |
| 本发布范围 | 提示词、流程、适配器、合成例子 | 方法说明，没有检索实现 |

stage1_5 的相关片段校验可能减少模型输入，同时受切分、召回和片段拼接方式影响。v5 的全文输入更直接，但受上下文长度、规则数量和合同处理顺序影响。没有公开对照基准，不能据此声称任何路线的准确率更高。

## 整理时的改动

- 保留原始规则立场保护、Judge 反馈重试、防止重复候选/回退、参数区间化兼容和按合同迭代的主要设计。
- 调整润色提示词中可能引发凭空填入数值的表述：缺失参数应留待人工澄清，不强行量化。
- 增加把合同与规则看作待分析材料的提示，降低文本中混入其他指令造成的影响；这不是完整的提示注入防护。
- 替换原私有服务集成，提供独立 HTTP 边界和明确的离线模拟。公开版不携带原服务凭据、会话配置或地址。
- 按 ID 验证整批结果，不使用索引补位；保留完整原规则，不对原文或合同静默截断。
- 将异常、缺失字段或非法类型视为失败；失败保留当前规则，记录可追踪状态。

本项目没有加入新的法律知识库、训练模型或新的优化算法。方法效果、不同合同集合之间的泛化能力和最终规则质量都需要后续人工标注、真实服务验证与独立评估。
